# JPG 导出、文件大小预估、默认输出目录跟随文档（1.2.0）

## 背景目标

面板目前只导出 PNG（整图 / 选中图层两种范围）。用户希望：

1. 增加快速导出 JPG，带质量滑条；
2. 导出前能看到预估文件大小（PNG 和 JPG 都要）；
3. 打开 / 切换到一个已保存的文档时，输出目录默认是该文档所在文件夹；
4. 编号策略和默认目录策略做成可切换的设置项。

## 范围

### 1. 格式选择

- 面板新增「格式」分段按钮：`PNG` / `JPG`，记忆在 localStorage（如 `qpe.format`），默认 PNG。
- 整图模式、选中图层模式都支持 JPG。
- 主按钮文案随格式变化：「快速导出 PNG」/「快速导出 JPG」。
- 扩展名统一用小写 `.jpg`。

### 2. JPG 质量

- 刻度 **0–12**（对应 Photoshop `JPEGSaveOptions.quality`，即「另存为 JPEG」的品质档位），默认 **10**，记忆在 localStorage。
- 控件：滑条 + 旁边显示当前数值（可附「低/中/高/最佳」档位名）。仅在 JPG 格式时显示。
- 透明区域填**白色**，不修改源文档（在临时副本上合并 / 填底）。
- 非 8 位 RGB 文档沿用现有的「临时副本转 8 位 RGB」流程与提示。

### 3. 文件大小预估

- PNG 和 JPG 都显示，位置靠近「导出名称」预览，如「预计大小 约 1.2 MB」。
- 计算方式：宿主按**与真实导出相同的选项**把当前画面存到系统临时目录的临时文件，读 `File.length` 后立即删除。必须与实际导出一致（同一套保存选项构造函数）。
- 触发：滑条**松开后**、切换格式、切换文档、文档内容可能变化（沿用现有文档轮询）时自动重算；拖动中不算。计算中显示「正在估算…」，结果过期时标注，失败时显示「无法估算」而不是报错打断导出。
- 并发：新一次估算发起时旧结果作废（沿用 `previewToken` 思路）；导出进行中不估算。
- 只在**整图模式**显示预估；选中图层模式不显示（逐项压一遍代价太高）。
- 估算不得改动源文档、不得修改 `app.displayDialogs` 后不恢复、不得在输出目录留下任何文件。

### 4. 编号策略（设置项）

- 选项：**共用序列（默认）** / 按格式分开计数。
- 共用：扫描目录时 `前缀-数字.png` 与 `前缀-数字.jpg`（大小写不敏感，`.jpeg` 也计入）一起取最大号，下一张 = max+1，不论导出哪种格式。
- 分开：只扫描与当前导出格式相同扩展名的文件。
- 两种策略下「不覆盖」保证不变：写入前仍按目标完整文件名检查存在。
- 规则放在 `jsx/core.jsx`，预览和导出共用，并补单测。

### 5. 默认输出目录（设置项）

- 选项：**跟随文档所在文件夹（默认）** / 记住上次保存的位置（即现有行为）。
- 跟随文档模式的行为与前缀自动填写一致：
  - 切换到**已保存**的文档 → 输出目录自动设为该文档所在文件夹（`status` 已返回 `path`）；
  - 同一文档内用户手动选过目录后，在该文档内保留手动目录，不再被覆盖；切到别的文档时重新按新文档填；
  - **未保存**的新文档（无路径）→ 沿用上次记住的目录；
  - 文档目录不可写时：照常显示，导出时沿用现有 `FOLDER_NOT_WRITABLE` 提示。
- 记住上次模式：保持当前 1.1.0 行为。
- 目录面板上可加一行小字说明当前目录来源（「文档所在文件夹」/「上次使用」/「手动选择」），可选。

### 6. 设置区

- 面板底部新增可折叠「设置」区（`<details>`），含上面两个设置项，记忆在 localStorage。默认折叠。
- 面板尺寸可适当调大以容纳新控件，保持在 CEP 面板可用范围内，深浅主题都要正常。

### 不在范围内

- 不改产品名 / 扩展 ID / 仓库名（仍叫 Photoshop Quick PNG Export）。
- 不做 WebP、GIF 等其他格式，不做 JPG 渐进式 / 元数据选项，不做自定义底色。
- 不发 GitHub Release、不打 tag。

## 方案比较

- **JPG 接口**：用户已选 0–12 刻度 → 用 `JPEGSaveOptions` + `saveAs(asCopy=true)`，不用 Save for Web（0–100）。
- **大小预估**：真实压一次临时文件 vs 用公式估算。公式对 PNG/JPG 误差都大，选真实压缩；代价用「松手后再算 + 只在整图模式」控制。
- **目录跟随**：复用前缀的「未手动编辑则自动填、切文档重置」状态机，而不是另起一套。

## 风险回滚

- **批量模式判空**：现有判空依赖重开**带透明的 PNG** 看 bounds。JPG 填白后没有透明，不能用同法判空。必须保证 JPG 批量下空图层 / 空组依然被跳过且不占号（例如先按现法判空再存 JPG，或其他经真机验证的方式），不能把空对象导出成纯白 JPG。
- **填白不改源文档**：所有合并 / 填底只发生在副本上；导出后副本关闭不保存。
- **估算耗时 / 卡顿**：大文档估算可能数秒，期间面板应仍可操作，导出优先；估算失败不影响导出。
- **临时文件残留**：估算文件写在系统临时目录并在 `finally` 中删除。
- **编号兼容**：共用序列下，老目录里只有 PNG 的情况结果与 1.1.0 相同。
- 回滚：功能在独立分支，未合并 main 前不影响已发布版本。

   - 16 位 / CMYK 文档导出 JPG 时沿用转换提示。
   - `app.displayDialogs` 在导出和估算后都恢复原值。
