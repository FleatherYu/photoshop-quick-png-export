# 选中图层拼图导出（1.3.0）

## 背景目标

「选中图层」模式把每个选中对象各导出一张。用户想要一个新范围「拼图」：把选中的图层 / 组按网格拼成**一张**图导出，能设列数，能把拼好的图缩小到指定尺寸。

例：6 个图层、画布 400×400、3 列 → 拼成 1200×800；把目标宽填 300 → 导出 300×200。

## 范围

### 1. 入口

- 「范围」分段按钮加第三项 **拼图**（整图 / 选中图层 / 拼图），沿用 `qpe.mode` 记忆。
- 拼图模式读取 Photoshop 当前选中的图层 / 组，选择规则与「选中图层」模式完全一致：图层面板从上到下排序；父组和子层同时选中时只取父组；明确选中的隐藏图层也参与；空对象和依赖外部的对象（剪贴、混合、调整层等）跳过，不占格子，在结果里说明原因。复用现有的选择读取、去重、依赖判断和隔离显示逻辑，不另写一套。
- 主按钮文案：「导出拼图 PNG」/「导出拼图 JPG」。

### 2. 格子

- **每格 = 整张画布尺寸**（文档宽 × 高）。每个对象按「选中图层」模式的隔离方式渲染，保持它在画布上的原位置，不裁切、不居中。
- 格子之间**没有间距**，没有外边距。
- 填充顺序：按排序结果从左到右、从上到下（行优先）。
- 背景：PNG 透明；JPG 透明处和末尾空格子都填白色（与 1.2.0 JPG 规则一致）。末尾没填满的格子留空（PNG 透明 / JPG 白色）。

### 3. 列数

- 用户只设**列数**，行数 = ceil(有效对象数 ÷ 列数)，面板显示「N 张 → C 列 × R 行」。
- 默认（自动）：列数 = ceil(√N)。用户改过列数后记住（localStorage），列数大于 N 时按 N 处理并提示。
- 有效对象数以宿主预览给出的为准（扣除跳过项后）。

### 4. 输出尺寸

- 显示原始拼图尺寸：`列数 × 画布宽` × `行数 × 画布高`。
- 两个输入框：**目标宽**、**目标高**，锁定比例：填一个，另一个自动按比例算出（四舍五入，至少 1 px）。都不填 = 原始尺寸。
- 只允许缩小或保持原尺寸；输入大于原始尺寸时提示，不放大。
- 缩放在最终拼好的图上做一次，用 Bicubic（或 PS CC 2019 里经实测最适合缩小的重采样方法）。
- 面板实时显示「原始 1200×800 → 导出 300×200」。
- 目标尺寸记住吗：**不记住**，换选择或文档后清空（尺寸依赖画布和数量，记住容易误用）。

### 5. 导出

- 一次导出一张文件，命名沿用 `前缀-编号.png/.jpg`，编号策略、输出目录、格式、JPG 质量全部复用 1.2.0 的设置与规则；不覆盖已有文件。
- 非 8 位 RGB 文档沿用临时副本转换流程和提示。
- 源文档不被修改：所有操作在副本 / 新建临时文档上进行，结束关闭，`app.displayDialogs` 恢复。
- 有效对象为 0（全部跳过）时不导出，说明原因。
- 导出结果显示文件路径、最终像素尺寸、实际放入的对象数和跳过列表。
- 文件大小预估：拼图模式**不做**（需要先完整拼一次）。显示像素尺寸即可。
- 和「选中图层」一样，导出前比对 `selectionKey`，选择变了就提示刷新。

### 不在范围内

- 格子间距、外边距、背景色选择、裁到内容、对齐方式、列优先填充、放大。
- 不改产品名 / 扩展 ID。不打 tag、不发 Release。

## 方案比较

- **格子内容**：裁到图层内容 vs 整张画布。用户选整张画布：每格和画布等大，位置不变，多层合起来能一一对照。
- **合成方式**（实现方实测决定）：例如每个对象像「选中图层」那样导出到临时 PNG，再在新建文档里按网格放置；或在副本里逐个复制合并结果粘到大画布。要求像素结果正确、透明保留、不留临时文件。

## 风险回滚

- 大网格可能非常大（如 20 张 4000×4000 → 20000×16000），内存 / 速度压力大。超过 Photoshop 文档上限（300000 px）时给出明确错误；导出过程失败时不留半成品文件和临时文档。
- 判空、依赖跳过必须与「选中图层」模式行为一致，否则同一选择在两种模式下结果不同。
- 回滚：在独立分支开发，合并 main 前不影响现有功能。

## 剩余问题

- 无阻塞问题。列数控件样式（数字框 / 步进器）、尺寸输入框排布由实现方按现有风格决定。
